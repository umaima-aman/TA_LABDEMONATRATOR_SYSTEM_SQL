**TA and Lab Demonstrator System**

This project focuses on designing a database system for managing Teaching Assistants (TAs) and Lab Demonstrators (LDs) in an educational institution. It provides a structured way to manage users, task assignments, availability, submissions, and performance feedback.
The system covers:
 Management of administrators, faculty members, TAs, and Lab Demonstrators.
 Task creation and assignment.
 TA and Lab Demonstrator availability.
 Task submissions and their status.
 Faculty feedback and performance evaluation.
 Management of submission attachments.

**Project Documentation**

The Project.docx provides the complete project documentation, including the introduction, project scope and objectives, system description, functional requirements for different user roles, project planning, questionnaire responses, ERD, EERD, relational schema, database normalization (1NF, 2NF, and 3NF), and user documentation.

**SQL Queries**

The SQL script includes database and table creation, sample data insertion, and queries to retrieve and analyze information. It demonstrates:
1. Joins and subqueries.
2. Aggregate functions.
3. 'GROUP BY' and 'HAVING'.
4. Retrieval of task, assignment, submission, and user-related information.

The SQL queries can be explored and executed in a database environment that supports SQL. The provided script uses MySQL syntax, so MySQL or a compatible database system is required to execute it without modifications.
